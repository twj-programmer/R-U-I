## 一、数据库设计

### 1.1 合同主表

**表名**: `crm_contract`

| 字段名 | 类型 | 长度/精度 | 约束 | 说明 |
|:---|:---|:---|:---|:---|
| `id` | bigint | - | PRIMARY KEY, AUTO_INCREMENT | 主键 |
| `name` | varchar | 128 | NOT NULL | 合同名称 |
| `no` | varchar | 128 | NOT NULL, UNIQUE | 合同编号 |
| `customer_id` | bigint | - | NOT NULL, FOREIGN KEY | 客户编号 |
| `business_id` | bigint | - | NULL, FOREIGN KEY | 商机编号 |

| `sign_user_id` | bigint | - | NULL, FOREIGN KEY | 公司签约人 |
| `contract_type` | tinyint | - | NOT NULL, DEFAULT 1 | 合同类型：1-销售，2-采购，3-服务 |
| `order_date` | datetime | - | NOT NULL | 下单日期 |
| `start_time` | datetime | - | NOT NULL | 开始时间 |
| `end_time` | datetime | - | NULL | 结束时间 |
| `total_product_price` | decimal | 24,6 | NOT NULL, DEFAULT 0 | 产品总金额 |
| `discount_percent` | decimal | 24,6 | NULL | 整单折扣 |

| `audit_status` | tinyint | - | NOT NULL, DEFAULT 0 | 审批状态 |
| `audit_remark` | varchar | 1000 | NULL | 审批意见 |
| `audit_time` | datetime | NULL | NULL | 审批时间 |
| `remark` | varchar | 500 | NULL | 备注 |
| `tenant_id` | bigint | - | NOT NULL, DEFAULT 0 | 租户ID |
| `creator` | varchar | 64 | NOT NULL | 创建人 |
| `create_time` | datetime | - | NOT NULL | 创建时间 |
| `updater` | varchar | 64 | NULL | 更新人 |
| `update_time` | datetime | - | NULL | 更新时间 |
| `deleted` | bit | - | NOT NULL, DEFAULT 0 | 删除标志 |

## 六、数据权限设计

### 6.1 数据可见范围

| 角色 | 可见范围 | 说明 |
|:---|:---|:---|
| 系统管理员 | 全部合同 | 无限制 |
| 销售经理 | 本部门及下属部门合同 | 部门数据权限 |
| 销售代表 | 本人负责的合同 | 负责人数据权限 |
| 财务专员 | 全部合同 | 业务需要 |

### 6.2 数据权限字段

| 字段 | 权限类型 | 说明 |
|:---|:---|:---|
| `tenant_id` | 租户隔离 | 多租户数据隔离 |
| `owner_user_id` | 负责人权限 | 只能查看自己负责的合同 |
| `department_id` | 部门权限 | 只能查看本部门合同 |
