## 一、需求概述

### 1.1 业务背景

营销人员需要追踪消息发送状态，了解发送成功率，对失败消息进行重试，以及统计发送效果。

### 1.2 功能目标

| 目标 | 描述 |
|------|------|
| 发送记录存储 | 记录每一条消息的发送详情 |
| 状态追踪 | 实时追踪发送状态（待发送、发送中、成功、失败） |
| 失败重试 | 支持对失败消息进行重试发送 |
| 发送统计 | 统计发送总量、成功率、失败率 |
| 详情查看 | 查看单条消息的发送详情和失败原因 |

## 四、业务流程

### 4.1 发送流程

```
创建发送任务 → 生成发送记录列表 → 逐条发送 → 更新发送状态 → 更新任务统计
```

### 4.2 失败重试流程

```
检测失败记录 → 判断重试次数 < 最大重试次数 → 执行重试 → 更新状态和重试次数
```

### 4.3 状态流转

```
待发送 → 发送中 → 成功
              ↘ 失败 → 重试 → 发送中 → ...
```

## 五、重试策略

### 5.1 重试规则

| 规则 | 说明 |
|------|------|
| 最大重试次数 | 默认3次，可配置 |
| 重试间隔 | 第一次重试间隔5分钟，第二次10分钟，第三次30分钟 |
| 重试触发 | 支持手动重试和自动重试 |
| 失败处理 | 超过最大重试次数后，标记为最终失败，记录失败原因 |

### 5.2 自动重试机制

- 使用定时任务扫描失败记录
- 按重试间隔策略执行自动重试
- 重试时更新发送时间和重试次数

## 七、验收标准

| 序号 | 验收项 | 验收标准 |
|------|--------|----------|
| 1 | 发送记录 | 每条消息发送后生成发送记录 |
| 2 | 状态更新 | 发送状态实时更新（待发送→发送中→成功/失败） |
| 3 | 失败重试 | 支持手动重试和自动重试，重试次数正确记录 |
| 4 | 发送统计 | 统计发送总量、成功率、失败率准确 |
| 5 | 任务管理 | 支持创建、启动、取消发送任务 |
| 6 | 失败原因 | 失败时记录详细失败原因 |
