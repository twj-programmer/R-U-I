## 一、需求概述

### 1.1 业务背景

营销人员需要通过数据指标评估营销活动效果，优化营销策略，提升ROI。

### 1.2 功能目标

| 目标 | 描述 |
|------|------|
| 发送指标 | 发送总量、成功率、失败率 |
| 邮件指标 | 打开率、点击率、退订率 |
| 转化指标 | 转化率、新增客户数、新增商机数 |
| ROI指标 | 投入产出比、成本收益分析 |
| 实时报表 | 支持按时间、渠道、模板维度统计 |

## 二、指标定义

### 2.1 发送指标

| 指标名称 | 计算公式 | 说明 |
|----------|----------|------|
| 发送总量 | COUNT(*) | 累计发送消息数量 |
| 成功数量 | COUNT(status=2) | 发送成功数量 |
| 失败数量 | COUNT(status=3) | 发送失败数量 |
| 成功率 | 成功数量 / 发送总量 × 100% | 发送成功比例 |
| 失败率 | 失败数量 / 发送总量 × 100% | 发送失败比例 |
| 平均发送时间 | AVG(success_time - send_time) | 平均发送耗时 |

### 2.2 邮件指标

| 指标名称 | 计算公式 | 说明 |
|----------|----------|------|
| 打开率 | 打开次数 / 成功发送数量 × 100% | 邮件被打开的比例 |
| 点击率 | 点击次数 / 打开次数 × 100% | 邮件链接被点击的比例 |
| 退订率 | 退订数量 / 成功发送数量 × 100% | 邮件被退订的比例 |
| 平均打开时间 | AVG(open_time - success_time) | 发送到打开的平均时间 |

### 2.3 转化指标

| 指标名称 | 计算公式 | 说明 |
|----------|----------|------|
| 转化率 | 转化数量 / 成功发送数量 × 100% | 收到消息后产生转化的比例 |
| 新增客户数 | COUNT(新增客户) | 营销活动带来的新增客户数量 |
| 新增商机数 | COUNT(新增商机) | 营销活动带来的新增商机数量 |
| 新增合同数 | COUNT(新增合同) | 营销活动带来的新增合同数量 |
| 转化金额 | SUM(转化合同金额) | 营销活动带来的合同总金额 |

### 2.4 ROI指标

| 指标名称 | 计算公式 | 说明 |
|----------|----------|------|
| 投入成本 | SUM(营销费用) | 营销活动总投入 |
| 收益金额 | SUM(转化合同金额) | 营销活动带来的收益 |
| ROI | 收益金额 / 投入成本 × 100% | 投入产出比 |
| 回本周期 | 投入成本 / 月均收益 | 收回成本所需时间 |

## 三、数据模型设计

### 3.1 指标统计表（crm_marketing_statistics）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | PRIMARY KEY | 主键ID |
| tenant_id | BIGINT | NOT NULL | 租户ID |
| stat_date | DATE | NOT NULL | 统计日期 |
| stat_type | TINYINT | NOT NULL | 统计类型：1-日报，2-周报，3-月报 |
| send_total | INT | NOT NULL DEFAULT 0 | 发送总量 |
| send_success | INT | NOT NULL DEFAULT 0 | 成功数量 |
| send_fail | INT | NOT NULL DEFAULT 0 | 失败数量 |
| email_open_count | INT | NOT NULL DEFAULT 0 | 邮件打开次数 |
| email_click_count | INT | NOT NULL DEFAULT 0 | 邮件点击次数 |
| email_unsubscribe_count | INT | NOT NULL DEFAULT 0 | 邮件退订数量 |
| convert_count | INT | NOT NULL DEFAULT 0 | 转化数量 |
| new_customer_count | INT | NOT NULL DEFAULT 0 | 新增客户数 |
| new_business_count | INT | NOT NULL DEFAULT 0 | 新增商机数 |
| new_contract_count | INT | NOT NULL DEFAULT 0 | 新增合同数 |
| convert_amount | DECIMAL(18,2) | NOT NULL DEFAULT 0 | 转化金额 |
| cost_amount | DECIMAL(18,2) | NOT NULL DEFAULT 0 | 投入成本 |
| create_time | DATETIME | NOT NULL | 创建时间 |

### 3.2 点击记录表（crm_marketing_click_record）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | PRIMARY KEY | 主键ID |
| tenant_id | BIGINT | NOT NULL | 租户ID |
| record_id | BIGINT | NOT NULL | 关联发送记录ID |
| url | VARCHAR(500) | NOT NULL | 点击URL |
| click_time | DATETIME | NOT NULL | 点击时间 |
| ip_address | VARCHAR(50) | | 点击IP地址 |
| user_agent | VARCHAR(500) | | 用户代理 |
| create_time | DATETIME | NOT NULL | 创建时间 |

## 五、统计流程

### 5.1 实时统计

```
消息发送 → 更新发送记录 → 实时计算发送指标
```

### 5.2 定时统计

```
定时任务触发 → 计算当日指标 → 更新指标统计表
```

### 5.3 点击追踪

```
用户点击链接 → 记录点击日志 → 更新点击统计 → 计算点击率
```
