## 一、需求概述

### 1.1 业务背景

为控制营销风险，群发消息需经过审批流程，确保发送内容合规、发送范围合理。

### 1.2 功能目标

| 目标 | 描述 |
|------|------|
| 群发审核 | 群发任务提交后需经过审批才能发送 |
| 审批流程 | 支持多级审批、审批人指定、审批意见 |
| 权限控制 | 不同角色有不同的审核权限 |
| 状态联动 | 审批状态与发送任务状态联动 |
| 审核记录 | 完整记录审核过程和意见 |

## 四、业务流程

### 4.1 审核流程

```
创建群发任务 → 提交审核申请 → 启动BPM流程 → 审核人审核 → 审核通过/驳回 → 更新任务状态
```

### 4.2 状态流转

```
待审核 → 审核中 → 已通过 → 发送任务启动
              ↘ 已驳回 → 任务终止（可修改后重新提交）
```

### 4.3 BPM流程配置

| 流程节点 | 说明 | 角色 |
|----------|------|------|
| 提交申请 | 申请人提交审核 | 市场人员 |
| 一级审核 | 部门负责人审核 | 部门负责人 |
| 二级审核 | 市场总监审核（大额/大量发送） | 市场总监 |
| 审核通过 | 流程结束，允许发送 | - |
| 审核驳回 | 流程结束，任务终止 | - |

## 五、权限控制

### 5.1 角色权限

| 角色 | 权限 |
|------|------|
| 市场人员 | 创建审核申请、撤回申请、查看自己的申请 |
| 部门负责人 | 审核本部门的申请、查看申请详情 |
| 市场总监 | 审核大额/大量发送申请、查看所有申请 |
| 管理员 | 查看所有申请、强制通过/驳回 |

### 5.2 审核阈值

| 阈值类型 | 阈值 | 触发条件 |
|----------|------|----------|
| 发送数量阈值 | 100人 | 超过100人需二级审核 |
| 发送频率阈值 | 1次/小时 | 同一模板1小时内最多发送1次 |
| 敏感词检查 | - | 内容包含敏感词自动拦截 |
