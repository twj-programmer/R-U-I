## 一、需求概述

### 1.1 业务背景

营销人员需要创建和管理标准化的邮件/短信模板，以便快速触达客户，提升营销效率和品牌一致性。

### 1.2 功能目标

| 目标 | 描述 |
|------|------|
| 模板管理 | 支持邮件模板和短信模板的创建、编辑、删除、查询 |
| 变量替换 | 支持模板中使用变量（如客户姓名、节日名称等），发送时自动替换 |
| 模板预览 | 支持模板预览，预览时可填入测试数据查看效果 |
| 模板分类 | 支持模板按类型、场景分类管理 |
| 权限控制 | 支持模板的可见范围和编辑权限控制 |

## 三、API接口设计

### 3.1 模板管理接口

| API路径 | HTTP方法 | 说明 | 权限 |
|---------|----------|------|------|
| `/crm/marketing/template/create` | POST | 创建模板 | crm:marketing:template:create |
| `/crm/marketing/template/update` | PUT | 更新模板 | crm:marketing:template:update |
| `/crm/marketing/template/delete` | DELETE | 删除模板 | crm:marketing:template:delete |
| `/crm/marketing/template/get` | GET | 获取模板详情 | crm:marketing:template:query |
| `/crm/marketing/template/page` | GET | 分页查询模板 | crm:marketing:template:query |
| `/crm/marketing/template/preview` | POST | 预览模板 | crm:marketing:template:query |
| `/crm/marketing/template/status` | PUT | 启用/禁用模板 | crm:marketing:template:update |

### 3.2 请求响应示例

**创建模板请求**
```json
{
  "name": "生日祝福模板",
  "type": 1,
  "category": "祝福",
  "subject": "生日祝福",
  "content": "<html><body>亲爱的{{customerName}}，祝您生日快乐！</body></html>",
  "variables": [
    {"name": "customerName", "label": "客户姓名", "type": "string", "defaultValue": ""}
  ],
  "description": "客户生日祝福邮件模板"
}
```


## 四、业务流程

### 4.1 模板创建流程

```
输入模板信息 → 校验变量格式 → 保存模板 → 返回模板ID
```

### 4.2 模板预览流程

```
选择模板 → 输入测试数据 → 变量替换 → 返回预览内容
```

### 4.3 模板使用流程

```
选择模板 → 获取变量定义 → 填充实际数据 → 变量替换 → 生成最终内容 → 发送
```

## 五、变量替换规则

### 5.1 变量格式

模板内容中使用 `{{变量名}}` 作为变量占位符，如 `{{customerName}}`、`{{festivalName}}`。

### 5.2 变量类型

| 类型 | 说明 | 示例 |
|------|------|------|
| string | 字符串 | 客户姓名、节日名称 |
| number | 数字 | 优惠金额、订单金额 |
| date | 日期 | 有效期、发送日期 |
| datetime | 日期时间 | 创建时间、更新时间 |

### 5.3 替换规则

1. 变量不存在于测试数据中时，使用默认值（若未设置默认值则为空字符串）
2. 日期类型变量支持格式化，如 `{{expireDate:yyyy-MM-dd}}`
3. 数字类型变量支持格式化，如 `{{amount:¥#,##0.00}}`
