## 联调验证项

### 1. BPM 状态映射

| BPM 事件 | CRM auditStatus | 验证方法 |
|---|---|---|
| BPM 通过 (2) | 20 | BPM完成审批 → 刷新回款列表 → 状态=审批通过 |
| BPM 驳回 (3) | 30 | BPM驳回 → 状态=审批拒绝 |
| BPM 取消 (4) | 40 | BPM撤回 → 状态=已取消（依赖 D2-APR-01 修复） |

### 2. OA 待办同步

| 验证项 | 方法 |
|---|---|
| 待审批回款列表显示正确 | CRM 待办 → 待审核回款 → 列表匹配 |
| 点击"查看审批"跳转 BPM 详情 | 点击 → BpmProcessInstanceDetail |
| 审批通过后待办消失 | BPM通过 → 刷新待办 → 不再出现 |

### 3. 回款页面五态展示

| 状态 | 值 | 列表标签 | 详情标签 |
|---|---|---|---|
| 草稿 | 0 | 未提交 | 未提交 |
| 审批中 | 10 | 审批中 | 审批中 |
| 审批通过 | 20 | 审核通过 | 审核通过 |
| 审批拒绝 | 30 | 审核不通过 | 审核不通过 |
| 已取消 | 40 | 已取消 | 已取消 |

### 4. 空 process_instance_id 容错

| 场景 | 预期 |
|---|---|
| 草稿回款点击"查看审批" | 不适用（草稿显示"提交审批"按钮） |
| auditStatus≠0 但 processInstanceId 为空 | 点击"查看审批" → 弹 warning 提示 |

### 5. 权限验证

| 场景 | 预期 |
|---|---|
| 无 crm:receivable:query 权限 | 看不到回款菜单 |
| 无 crm:receivable:update 权限 | 看不到提交/编辑按钮 |
| 跨租户 | 租户A看不到租户B的回款 |
