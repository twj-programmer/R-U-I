## 一、核心业务链依赖

### 1.1 客户 → 商机 → 订单 → 财务 主链

```
客户域          商机域          订单/合同域      财务/回款域
   ↓              ↓              ↓                ↓
 crm_customer → crm_business → crm_contract → crm_receivable
 crm_contact    crm_business_   crm_contract_   crm_receivable_
                product         product         plan
 crm_clue       crm_business_   CrmAuditStatus  ReceivableStatus
                status
```

### 1.2 字段依赖关系

| 来源域 | 目标域 | 依赖字段 | 用途 | 负责人 |
|--------|--------|----------|------|--------|
| **客户域** | 商机域 | `customer_id`, `customer_name`, `contact_id` | 商机关联客户和联系人 | 刘焘玮 |
| **客户域** | 商机域 | `customer_source`, `customer_level` | 商机创建时继承客户属性 | 刘焘玮 |
| **客户域** | 订单域 | `customer_id`, `customer_name` | 合同关联客户 | 李祖豪 |
| **商机域** | 订单域 | `business_id`, `business_name`, `business_amount` | 合同关联商机，继承金额 | 黄金戈 |
| **商机域** | 订单域 | `product_list` (商机产品行) | 合同产品明细来源 | 黄金戈 |

| 上游域 | 上游状态 | 下游域 | 下游状态 | 触发条件 | 负责人 |

## 六、依赖冲突与解决策略

| 冲突项 | 描述 | 解决策略 | 负责人 |
|--------|------|----------|--------|
| 客户删除 | 删除客户时商机/合同引用失效 | 禁止删除有活跃商机/合同的客户，仅支持停用 | 刘焘玮 |
| 商机删除 | 删除商机时产品行和跟进记录处理 | 保留历史数据，标记删除状态 | 黄金戈 |
| 合同删除 | 删除合同时回款记录处理 | 禁止删除有回款记录的合同 | 李祖豪 |
| 产品删除 | 产品被商机引用时删除保护 | 产品停用而非删除，历史商机保留快照 | 黄金戈 |
| 审批回调 | BPM回调与CRM状态不一致 | 最终一致性，重试机制 | 李祖豪 |
| 客户停用 | 客户停用时营销消息发送 | 客户停用时禁止发送营销消息，已有发送记录保留 | - |
| 模板删除 | 删除模板时已有发送记录引用 | 模板软删除，已有发送记录保留引用 | - |
