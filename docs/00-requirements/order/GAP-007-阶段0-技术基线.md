## 二、现有合同数据模型

### 2.1 合同主表

**数据库表**: `crm_contract`（位于 `database/base/crm-2024-09-30.sql`）

| 字段名 | 类型 | 长度/精度 | 可复用为订单 | 说明 |
|:---|:---|:---|:---|:---|
| `id` | bigint | - | ✅ | 主键，可作为订单唯一标识 |
| `name` | varchar | 128 | ✅ | 合同名称，可复用为订单名称 |
| `no` | varchar | 128 | ✅ | 合同编号，可复用为订单编号 |
| `customer_id` | bigint | - | ✅ | 客户编号，订单必须关联客户 |
| `business_id` | bigint | - | ✅ | 商机编号，订单可关联商机 |
| `owner_user_id` | bigint | - | ✅ | 负责人，订单需要负责人 |
| `process_instance_id` | varchar | 64 | ✅ | 流程实例ID，审批关联 |
| `audit_status` | tinyint | - | ✅ | 审批状态，订单状态管理 |
| `order_date` | datetime | - | ✅ | 下单日期，订单核心字段 |
| `start_time` | datetime | - | ✅ | 开始时间，订单生效时间 |
| `end_time` | datetime | - | ✅ | 结束时间，订单到期时间 |
| `total_product_price` | decimal | 24,6 | ✅ | 产品总金额，订单明细金额 |
| `discount_percent` | decimal | 24,6 | ✅ | 整单折扣，订单折扣 |
| `total_price` | decimal | 10,2 | ✅ | 合同总金额，订单金额 |
| `sign_contact_id` | bigint | - | ✅ | 联系人编号，订单签约人 |
| `sign_user_id` | bigint | - | ✅ | 公司签约人，订单签约人 |
| `remark` | varchar | 500 | ✅ | 备注，订单备注 |

**结论**: 现有 `crm_contract` 表结构**完全满足订单映射需求**，无需新建 `crm_order` 表。

## 三、现有审批状态枚举

**文件**: `Server/mitedtsm-module-crm/src/main/java/com/meession/etm/module/crm/enums/common/CrmAuditStatusEnum.java`

| 状态值 | 枚举名 | 说明 | 映射订单状态 |
|:---|:---|:---|:---|
| 0 | DRAFT | 未提交（草稿） | 草稿 |
| 10 | PROCESS | 审批中 | 审批中 |
| 20 | APPROVE | 审核通过 | 已通过 |
| 30 | REJECT | 审核不通过（驳回） | 已驳回 |
| 40 | CANCEL | 已取消（撤回） | 已撤回 |

**结论**: 缺少"待审批"状态，需扩展。

## 六、差异分析

| 差异点 | 现有状态 | 期望状态 | 实现建议 |
|:---|:---|:---|:---|
| 订单模型 | 无独立订单表 | 合同即订单 | 复用 `crm_contract` |
| 合同类型 | 无类型区分 | 支持销售/采购/服务 | 新增 `contract_type` 字段 |
| 待审批状态 | 无 | 新增状态 | 扩展 `CrmAuditStatusEnum` |
| 审批意见 | 无存储 | 保存审批意见 | 新增 `audit_remark` 字段 |
| 通过后动作 | 无 | 更新商机/创建回款计划 | 扩展 `updateContractAuditStatus` |
| 驳回后动作 | 仅更新状态 | 保存驳回意见/发送通知 | 扩展 `updateContractAuditStatus` |
