## 2.4 非功能测试范围

### 2.4.1 性能测试

| 测试内容 | 测试工具 | 优先级 | 验证标准 |
|---------|---------|--------|---------|
| 接口响应时间 | JMeter / k6 | P1 | 95%请求响应时间 < 200ms |
| 并发用户数 | JMeter / k6 | P1 | 50并发用户下系统稳定运行 |
| 数据导入性能 | JMeter | P2 | 1000条客户数据导入 < 30秒 |
| 统计报表性能 | JMeter | P2 | 复杂统计查询响应时间 < 5秒 |
| 公海定时任务性能 | JMeter | P1 | 大批量客户掉入公海不锁表（分批处理每批500条） |
| 客户查重性能 | JMeter | P1 | 名称相似度计算响应时间 < 500ms |

| 测试内容 | 测试工具 | 优先级 | 验证标准 |

| SQL注入防护 | OWASP ZAP | P0 | 无SQL注入漏洞 |
| XSS攻击防护 | OWASP ZAP | P0 | 无XSS漏洞 |
| 接口越权访问 | 手动测试 | P0 | 无权限用户无法访问受限接口 |
| 敏感数据脱敏 | 手动测试 | P1 | 日志、接口返回中敏感数据已脱敏 |
| 认证绕过 | OWASP ZAP | P0 | 无认证绕过漏洞 |
