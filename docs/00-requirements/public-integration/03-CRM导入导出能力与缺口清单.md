# CRM 导入导出能力与缺口清单

> 当前角色：度量专员  
> 基线日期：2026-07-14  
> 盘点范围：CRM 后端 Controller、前端 API 和页面入口

## 1. 总体结论

- 按本次冻结的盘点基线，当前共有 **8 个后端导出接口**；客户列表和客户公海共用客户导出，因此前端可见为 **9 个导出入口**。
- 当前只有 **客户模块**具备正式批量导入、模板下载和导入结果反馈。
- 统计模块基线中暂无 Excel 导出接口；客户统计、漏斗、画像、排行榜和员工业绩的导出需求需要另行确认范围。
- 现有业务导出主要使用 `.xls`，文件格式和命名规则尚未统一。

## 3. 已有导入能力

| ID | 模块 | 能力 | 接口 | 权限 | 处理规则 |
|---|---|---|---|---|---|
| IMP-01 | 客户 | 下载模板 | `GET /crm/customer/get-import-template` | 当前代码未见独立权限注解 | 返回客户示例 `.xls` |
| IMP-02 | 客户 | 上传导入 | `POST /crm/customer/import` | `crm:customer:import` | 按客户名称判断重复；支持选择负责人和是否更新 |
| IMP-03 | 客户 | 结果反馈 | 同导入接口 | 同上 | 返回新增名称、更新名称、失败名称及原因 |

客户导入当前关键规则：

1. 客户名称为空的行被过滤；全部为空时整体失败；
2. 不存在同名客户时新增；
3. 存在同名客户且 `updateSupport=false` 时记录失败；
4. `updateSupport=true` 时更新原客户；
5. 指定负责人时创建 OWNER 数据权限；
6. 每条新增/更新记录操作日志。

## 4. 导出统一验收口径

| 维度 | 验收要求 |
|---|---|
| 筛选 | 导出条件必须与当前页面查询条件完全一致 |
| 数据权限 | 导出不得比页面查询范围更大；禁止通过参数扩大人员/租户范围 |
| 空数据 | 生成含表头的合法文件，或给出统一明确提示 |
| 文件名 | 建议 `CRM_<模块>_<yyyyMMddHHmmss>.<格式>`，具体格式评审后冻结 |
| 格式 | 当前以 `.xls` 为主；是否统一升级为 `.xlsx` 由组长和技术专员确认 |
| 金额 | 元，两位小数；原始高精度不得产生累计误差 |
| 时间 | 统一 `yyyy-MM-dd HH:mm:ss`，纯日期用 `yyyy-MM-dd` |
| 字典 | 导出显示名称，不直接输出难以理解的数字字典值 |
| 个人信息 | 手机、邮箱、地址等按角色决定是否脱敏 |
| 操作日志 | 重要批量导出应具备 export 类型访问日志 |

## 5. 导入统一验收口径

| 场景 | 最低要求 |
|---|---|
| 模板版本 | 模板应包含版本号或生成日期，并与当前字段一致 |
| 文件限制 | 仅允许指定 Excel 类型；限制单文件大小和最大行数 |
| 表头校验 | 缺列、错列、重复列必须给出明确错误 |
| 行级反馈 | 返回行号、业务主键、失败字段和失败原因 |
| 重复策略 | 明确跳过、覆盖或报错，不得静默更新 |
| 事务策略 | 明确整批回滚还是成功行提交；当前客户导入属于逐行结果汇总 |
| 字典校验 | 字典名称/编码必须可转换，失效值不得导入 |
| 关联校验 | 客户、负责人、部门等关联对象必须存在且同租户 |
| 权限 | 导入用户必须有 import 权限，对指定负责人也要校验可见范围 |
| 审计 | 记录文件名、操作者、时间、成功/失败数和失败明细 |
| 幂等 | 同一文件重复导入结果可预测，不产生无控制重复数据 |

## 6. 当前缺口和优先级

| GAP | 缺口 | 优先级 | 建议负责人 | 验收证据 |
|---|---|---|---|---|
| IO-01 | 客户统计、销售漏斗、画像、排行榜没有 Excel 导出 | P1 | 对应统计开发 | 接口、文件、数据对比 |
| IO-02 | 线索、联系人、商机、合同、回款、产品等没有批量导入 | P1/P2 | 需求确认后分模块 | 模板、导入结果、错误行 |
| IO-03 | 导出格式是否从 `.xls` 统一升级为 `.xlsx` 尚未决策 | P2 | 技术专员 | 兼容性评审 |
| IO-04 | 客户导入模板下载未见独立权限注解 | P1 | 客户模块开发 | 无权限接口结果 |
| IO-05 | 导入失败反馈需要核对是否包含原始 Excel 行号 | P1 | 客户模块开发 | 错误行报告 |
| IO-06 | 导出个人信息脱敏规则未冻结 | P1 | 组长/安全/业务 | 角色矩阵 |
| IO-07 | 各模块空数据、文件名、时间和金额格式不统一 | P1 | 全体开发 | 统一规范和回归 |
| IO-08 | 公海页面共用客户导出，需要确认筛选条件不会导出非公海客户 | P0 | 客户模块开发 | 页面/Excel 数据对比 |

## 7. 最小测试矩阵

| 类别 | 必测内容 |
|---|---|
| 正常 | 当前筛选、有数据、中文、金额、日期、字典显示 |
| 空数据 | 无数据文件/提示、表头完整 |
| 权限 | 无按钮、无接口权限、跨部门、跨租户、伪造负责人 |
| 边界 | 最大行数、大金额、零金额、超长文本、闰日、跨年 |
| 异常 | 损坏文件、错误扩展名、缺表头、非法字典、重复数据、关联不存在 |
| 幂等 | 同文件重复导入、导出重复点击、请求超时重试 |
| 兼容 | Excel/WPS 打开、中文文件名、浏览器下载 |
